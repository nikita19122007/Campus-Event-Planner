# Campus Event Planner

A collection of standalone Java programs and exercises for campus event planning, registration, certificates, passes, and event coordination.

## Requirements

- Java Development Kit (JDK) 21 or newer

## Run a program

From the project directory, compile and run a source file that contains a `main` method. For example:

```powershell
javac CampusPassSystem.java
java CampusPassSystem
```

Other entry points include `CampusCertificate`, `EventPlannerApplication`, `EventPlanner8A`, `EventPlanner8B`, `EventQuest`, `EventSync`, `Main`, `Planner`, `SmartEventPlanner`, and `ConstructorDemo`.

Compile and run each program separately. Some source files define classes with the same names, so compiling every `.java` file together is not supported.
